Weekly Meal Planner and Grocery List Generator

1. Project Abstract

The Weekly Meal Planner and Grocery List Generator is a Java-based application that helps users plan their meals for seven days. Users can select breakfast, lunch, and dinner, with multiple food items allowed for each meal. The system identifies the ingredients required for the selected foods, combines them into a grocery list, removes duplicate ingredients, sorts the list, and saves it in a text file.

2. Problem Statement

Planning meals for an entire week and preparing a grocery list manually can take time. The same ingredients may be needed for multiple meals, resulting in repeated items on the shopping list. This project simplifies weekly meal planning and automatically generates an organized grocery list.

3. Objectives

Plan breakfast, lunch, and dinner for seven days.

Allow multiple food items for each meal.

Display the complete weekly meal plan.

Search for a selected food in the plan.

Generate a sorted grocery list without duplicate ingredients.

Save the grocery list in a text file.

7. How to Run the Project

Install the Java Development Kit (JDK).

Open the project folder in Visual Studio Code.

Open the terminal in the project folder.

Compile the integrated program:

javac WeeklyMealPlanner.java

Run the program:

java WeeklyMealPlanner

Enter valid food names for breakfast, lunch, and dinner for all seven days.

Search for a food item when prompted.

View the generated grocery list in the terminal and in GroceryList.txt.

8. Output

The program displays the weekly meal plan and the generated grocery list. It removes duplicate ingredients, sorts the grocery items, and saves the list in GroceryList.txt.
